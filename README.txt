段取工房 オフライン版

このフォルダの中身を無料の置き場（GitHub Pages）に置き、スマホの「ホーム画面に追加」で使います。
一度開いておけば、そのあとは電波がなくても動きます。


■ 置き方（GitHub Pages。家のPCで5分ほど）

1. GitHub にサインインし、右上の「＋」→「New repository」を選ぶ。
   名前は dandori-kobo など。「Public」を選んで「Create repository」。
   ※無料のアカウントで GitHub Pages を使えるのは、公開（Public）のリポジトリだけです。
     置くのは道具の中身だけで、書いたデータはスマホの中にしか入りません。

2. 作ったリポジトリの画面で「uploading an existing file」（または「Add file」→「Upload files」）を選び、
   このフォルダの中のファイル8つ（index.html、sw.js、manifest.webmanifest、画像4つ、README.txt）を
   まとめてドラッグして「Commit changes」。
   ※フォルダごとではなく、中のファイルを入れてください。

3. 「Settings」→ 左の「Pages」を開き、「Build and deployment」の Source を「Deploy from a branch」、
   Branch を「main」と「/ (root)」にして「Save」。

4. 1〜2分待つと、同じ画面に https://（ユーザー名）.github.io/dandori-kobo/ のようなアドレスが出ます。


■ スマホに入れる

・iPhone … Safari でそのアドレスを開く → 共有ボタン →「ホーム画面に追加」
・Android … Chrome で開く → 右上のメニュー →「ホーム画面に追加」（「アプリをインストール」と出ることもあります）

ホーム画面のアイコンから開いて使ってください。
iPhone では、ブラウザのまま使うと、しばらく開かなかったときにデータが消えることがあります。


■ 家のPCとのやり取り（受け渡し）

・スマホ → PC
  オフライン版の「受け渡し」→「受け渡し用のファイルを作る」→「送る・保存する」。
  LINE やメールで自分に送るか、ファイルに保存します。
  家のPCで Claude の段取工房を開き、「受け渡し」→「ファイルを選ぶ」で取り込みます。

・PC → スマホ
  Claude の段取工房で同じように書き出し、スマホに送って、オフライン版の「受け渡し」で取り込みます。

・同じものを両方で直したときは、あとで直した方が残ります。
  片方で消したものは、取り込むともう片方でも消えます。


■ オフライン版でできないこと

・Claude を呼ぶ機能（台本やネーム写真からの下書き、英語プロンプト作り）。
  受け渡しで Claude の段取工房に取り込めば、そちらで使えます。


■ 新しい版に入れ替えるとき

GitHub のリポジトリに、新しいファイルを同じ名前で上書きアップロードします。
スマホでは、電波のある所で開き直すと新しい版になります（2回開くと確実です）。データはそのまま残ります。


■ データの控え

スマホを替えるときや念のための控えにも、「受け渡し用のファイル」がそのまま使えます。
