段取工房 オフライン版

このフォルダの中身を無料の置き場（GitHub Pages）に置き、スマホとPCに「インストール」して使います。
一度開いておけば、そのあとは電波がなくても動きます。
書いたデータ（カット表・台本・ネーム写真・キャラ）は、それぞれの端末の中にだけ保存されます。


■ 置き方（GitHub Pages。家のPCで5分ほど）

1. GitHub にサインインし、右上の「＋」→「New repository」を選ぶ。
   名前は dandori-kobo など。「Public」を選んで「Create repository」。
   ※無料のアカウントで GitHub Pages を使えるのは、公開（Public）のリポジトリだけです。
     置くのは道具の中身だけで、書いたデータは GitHub には一切上がりません。

2. 作ったリポジトリの画面で「uploading an existing file」（または「Add file」→「Upload files」）を選び、
   このフォルダの中のファイル9つ（index.html、sw.js、manifest.webmanifest、画像4つ、README.txt、FONT-LICENSE.txt）を
   まとめてドラッグして「Commit changes」。
   ※フォルダごとではなく、中のファイルを入れてください。

3. 「Settings」→ 左の「Pages」を開き、「Build and deployment」の Source を「Deploy from a branch」、
   Branch を「main」と「/ (root)」にして「Save」。

4. 1〜2分待ってから Pages の画面を再読み込みすると、上の方に
   「Your site is live at https://（ユーザー名）.github.io/dandori-kobo/」と出ます。


■ 端末に入れる

・Android … Chrome でそのアドレスを開く → 右上のメニュー →「ホーム画面に追加」→「インストール」
            （「ショートカットを作成」ではなく「インストール」を選びます）
・PC      … Chrome でそのアドレスを開く → アドレスバー右端のインストールのアイコン
            （Edge ならメニューの「アプリ」→「このサイトをアプリとしてインストール」）
・iPhone  … Safari で開く → 共有ボタン →「ホーム画面に追加」

入れたあとは、アイコンから開いて使ってください。


■ タネ・プロット・段取り（頭の中でどこまで決まっているかで分ける）

・タネ     … 一言でしか言えないもの。ホームの一番上の欄に書いて「しまう」。写真だけでもしまえます。
・プロット … 誰が・何をして・どこが見せ場かまで言えるもの。タネを開いて「プロットにする」。
             形式・見せ場・流れ・決まってないこと・資料写真を書けます。
・段取り   … 1コマずつ絵が浮かぶもの（カット表）。「段取りに上げる」で、プロットからシーンやコマを作ります。
             タネとプロットは、台本タブの「はじまり」に残ります。

全部の作品の「決まってないこと」は、ホームのボタンからまとめて見られます。
タネ・プロット・資料写真も、鍵付きファイルで一緒に運べます。


■ スマホとPCのやり取り（受け渡し）

1. 最初の1回だけ、スマホとPCの両方で、受け渡し画面の「合言葉」に同じ合言葉を覚えさせる。
2. 渡す側で「鍵付きファイルを作る」→「送る・保存する」。
   Quick Share、USB ケーブル、LINE、メールなど、どの方法で運んでもかまいません。
   ファイルには合言葉から作った鍵がかかっているので、途中で中身を読まれることはありません。
3. 受け取る側で「ファイルを選ぶ」→ 何が変わるかを確かめて「取り込む」。

・同じものを両方で直したときは、あとで直した方が残ります。
・片方で消したものは、取り込むともう片方でも消えます。
・合言葉を忘れると、鍵付きのファイルは誰にも開けません（作り直しになります）。


■ Claude に送られない理由

・このオフライン版は、ページそのものに「どこにも通信しない」という指定（CSP）を書き込んであります。
  プログラムが仮に送ろうとしても、ブラウザがその場で止めます。文字の形（フォント）もページの中に入れてあり、
  外のサイトに取りに行くこともありません。
・Claude を呼ぶ部品や、Claude の保存先につながる部品は、オフライン版には入っていません。
・スマホとPCの間のファイルには鍵がかかっています。Claude の段取工房には、その鍵を開ける部品自体が入っていないので、
  間違って取り込もうとしても開けません。
・Claude に渡るのは、作品の設定で「Claude の段取工房にも渡す」をオンにした作品を、
  「Claude 行きのファイルを作る」で書き出し、自分で Claude の段取工房に取り込んだときだけです。
  Claude の段取工房の側も、オンになっていない作品は受け取りません。

確かめたいときは、PCで段取工房を開いて F12 →「ネットワーク」タブを見てください。
最初に自分の置き場（github.io）からページを読み込むほかは、どこにも通信していないのが分かります。


■ オフライン版でできないこと

・Claude を呼ぶ機能（台本やネーム写真からの下書き、英語プロンプト作り）。
  英語プロンプトは、発注書をコピーして家の変換（ローカルLLMなど）にかけてください。


■ 新しい版に入れ替えるとき

GitHub のリポジトリに、新しいファイルを同じ名前で上書きアップロードします。
端末では、電波のある所で開き直すと新しい版になります（2回開くと確実です）。データはそのまま残ります。


■ データの控え

ブラウザの「閲覧データを削除」でサイトのデータまで消すと、段取工房のデータも消えます。
念のため、ときどき鍵付きファイルを作って保存しておくと、控えになります。
